De toutes les briques d'une IA vocale, la synthèse vocale est celle qui envoie le plus de contenu chez un tiers, phrase après phrase, pendant toute la conversation. Quand ce contenu transite par des serveurs américains soumis au Cloud Act, la souveraineté devient un sujet concret. [Gradium](https://gradium.ai), startup française issue du laboratoire [Kyutai](https://kyutai.org), propose un TTS avec des serveurs européens.

Le package `@micdrop/gradium` fait la connexion, la région européenne est le réglage par défaut, et un fournisseur de secours prend le relais en cas de panne.

## Qu'est-ce que Gradium ?

Gradium est une startup parisienne fondée par d'anciens chercheurs de Meta, Google DeepMind, Google Brain et Jane Street. Elle a levé 70 millions de dollars en seed fin 2025 auprès de FirstMark Capital, Eurazeo et d'investisseurs comme Eric Schmidt et Yann LeCun.

Gradium développe des **modèles de langage audio-natifs** pour le text-to-speech et le speech-to-text en temps réel.

Gradium publie aussi Phonon, un TTS local construit sur Pocket TTS de Kyutai. Son modèle français, `phonon-40m-fr`, tourne dans votre serveur Node sans clé API avec [`@micdrop/phonon`](/docs/ai-integration/provided-integrations/phonon). Sur un MacBook Pro M2, nous avons mesuré le premier son entre 30 et 100 ms avec un seul cœur. Quand on transcrit l’audio avec Whisper, on retrouve le texte presque mot pour mot, date et heure comprises. Ce modèle propose 15 voix françaises. Il est pourtant sous licence CC BY-NC 4.0, qui interdit l’usage commercial. Le seul modèle Phonon utilisable librement dans un produit, `phonon-31m-en`, parle uniquement anglais. Pour un produit commercial en français, l’API hébergée de Gradium reste donc le bon choix. Nous avons comparé Phonon aux autres [voix françaises pour un agent vocal, hébergées ou locales](/blog/french-text-to-speech-voice-agent).

### Les caractéristiques de Gradium

| Caractéristique | Détail |
|---|---|
| **Voix disponibles** | 150+ voix dans 5 langues (FR, EN, DE, ES, PT) |
| **Clonage vocal** | À partir de 10 secondes d'audio |
| **Streaming** | WebSocket temps réel avec timestamps mot par mot |
| **Régions** | Serveurs EU et US au choix |
| **Formats audio** | PCM (8/16/24/48 kHz), WAV, Opus, µ-law, A-law |
| **Latence** | < 300 ms (time-to-first-byte) |
| **Code-switching** | Changement de langue en milieu de phrase |

### Gradium et la souveraineté des données

Le siège de Gradium est à Paris, celui d'ElevenLabs à New York et celui de Cartesia à San Francisco. La différence se joue sur quatre points :

- l'hébergement est européen par défaut, les données restent dans l'Union
- les plans Enterprise fonctionnent sans conservation des données
- un déploiement en cloud privé ou sur site reste possible
- Gradium relève du droit européen plutôt que du Cloud Act

Pour une administration, un établissement de santé ou une école, l'hébergement européen décide souvent du fournisseur retenu.

## Intégration avec Micdrop

[Micdrop](/) est un framework TypeScript open source pour ajouter des conversations vocales IA dans les applications web. Vous branchez Gradium en quelques lignes avec le package `@micdrop/gradium`.

### Installation

```bash
npm install @micdrop/server @micdrop/gradium
```

### Configuration de base

```typescript
import { MicdropServer } from '@micdrop/server'
import { GradiumTTS } from '@micdrop/gradium'

const tts = new GradiumTTS({
  apiKey: process.env.GRADIUM_API_KEY || '',
  voiceId: 'YOUR_VOICE_ID',
  region: 'eu', // Serveurs européens
  outputFormat: 'pcm_16000',
})

new MicdropServer(socket, {
  tts,
  agent, // Votre agent LLM
  stt,   // Votre fournisseur STT
})
```

La région `eu` est la valeur par défaut, et le trafic Gradium reste dans l'Union jusqu'à ce que vous choisissiez la région US.

### Configuration avancée de la voix

Trois réglages contrôlent le rendu de la voix :

```typescript
const tts = new GradiumTTS({
  apiKey: process.env.GRADIUM_API_KEY || '',
  voiceId: 'YOUR_VOICE_ID',
  region: 'eu',
  outputFormat: 'pcm_16000',
  jsonConfig: {
    temp: 0.7,          // Expressivité (0 → monotone, 1.4 → très expressif)
    cfg_coef: 2.0,      // Fidélité à la voix originale (1.0 → libre, 4.0 → fidèle)
    padding_bonus: 0,   // Vitesse (-4.0 → rapide, 4.0 → lent)
  },
})
```

## La stack souveraine complète

Gradium prononce les réponses. Avec [Mistral](https://mistral.ai) pour les écrire et [Gladia](https://gladia.io) pour transcrire la voix de l’utilisateur, la conversation passe par trois entreprises françaises. Pour [monter un agent vocal IA souverain](/blog/agent-vocal-ia-souverain) avec eux, choisissez la région européenne de chacun et hébergez aussi votre serveur dans l’Union.

## Stratégie de fallback pour la résilience

Un fournisseur finit toujours par tomber. Micdrop embarque un fallback entre fournisseurs TTS. Si Gradium répond en erreur, le serveur bascule sur un fournisseur de secours et la conversation continue.

### TTS avec fallback

```typescript
import { FallbackTTS } from '@micdrop/server'
import { GradiumTTS } from '@micdrop/gradium'
import { ElevenLabsTTS } from '@micdrop/elevenlabs'

const tts = new FallbackTTS({
  factories: [
    // Fournisseur principal : Gradium (souverain)
    () =>
      new GradiumTTS({
        apiKey: process.env.GRADIUM_API_KEY || '',
        voiceId: process.env.GRADIUM_VOICE_ID || '',
        region: 'eu',
        maxRetry: 2,
      }),
    // Secours : ElevenLabs
    () =>
      new ElevenLabsTTS({
        apiKey: process.env.ELEVENLABS_API_KEY || '',
        voiceId: process.env.ELEVENLABS_VOICE_ID || '',
        maxRetry: 3,
      }),
  ],
})
```

Le `FallbackTTS` fonctionne ainsi :

1. Il utilise le premier fournisseur (Gradium) par défaut
2. Si Gradium échoue après ses retries, il **bufferise le texte** en cours
3. Il bascule sur ElevenLabs
4. Le texte bufferisé est **rejoué** sur le nouveau fournisseur
5. L'utilisateur perçoit une micro-interruption, et rien de plus

Vous gardez donc Gradium au quotidien sans perdre la conversation les jours de panne. ElevenLabs, le secours choisi ici, traite alors le texte hors de l’Union. Prenez plutôt Voxtral Speech 3 comme secours, sur le point de terminaison européen de Mistral, pour garder toute la chaîne en Europe avec moins de voix françaises au choix.

## Comparaison avec les alternatives

| Critère | Gradium | ElevenLabs | Cartesia |
|---------|---------|------------|----------|
| **Siège** | Paris, France | New York, USA | San Francisco, USA |
| **Serveurs EU** | Natif | Non prioritaire | Non |
| **Rétention données** | Zéro (Enterprise) | Standard US | Standard US |
| **Cloud Act** | Non soumis | Soumis | Soumis |
| **Langues** | 5 | 70+ | 15 |
| **Clonage vocal** | 10s | 30s | 3s |
| **Streaming WebSocket** | Oui | Oui | Oui |
| **Tarification** | Par caractère | Par caractère | Par caractère |

ElevenLabs reste devant sur le nombre de langues et Cartesia clone une voix à partir d'un extrait plus court. Les deux traitent par défaut vos données aux États-Unis.

## Gradium ou Voxtral Speech 3 pour une voix française

Mistral, autre entreprise française, vend aussi une synthèse vocale, Voxtral Speech 3. Micdrop la branche avec `MistralTTS`, dans le package [`@micdrop/mistral`](/docs/ai-integration/provided-integrations/mistral). Les deux fournisseurs génèrent l’audio en Europe, mais ils diffèrent sur le prix, les voix et la façon de recevoir le texte. Nous avons relevé les prix sur les pages tarifaires des deux fournisseurs le 21 octobre 2026.

| Critère | Gradium | Voxtral Speech 3 |
|---|---|---|
| **Voix françaises** | Une partie des 150+ voix du catalogue | Quatre voix prêtes à l’emploi, Marie (`voice_592`), Camille (`voice_3141`), Manon (`voice_3137`) et Lea (`voice_589`) |
| **Clonage vocal** | À partir de 10 secondes d’audio | À partir de quelques secondes d’audio (`refAudio`) |
| **Expressivité** | Réglages `temp`, `cfg_coef` et `padding_bonus` | Balises d’émotion et de rythme comme `[emotion=happy]`, interprétées plutôt que lues |
| **Prix** | 1 crédit par caractère, de 36 à 58 $ le million selon l’offre | 13 $ le million de caractères |
| **Région européenne** | `region: 'eu'`, la valeur par défaut | `baseUrl: 'https://api.eu.mistral.ai'` |
| **Envoi du texte** | En continu sur un WebSocket | Une requête par phrase |
| **Premier son** | 258 ms en médiane, selon Gradium | 0,5 à 0,6 s par phrase, mesuré par nos soins |

`GradiumTTS` envoie la réponse de l’agent à Gradium au fur et à mesure que le LLM l’écrit, sur un seul WebSocket. L’API de Mistral attend un texte complet par requête, donc `MistralTTS` découpe la réponse en phrases et envoie une requête par phrase. Mistral génère chaque phrase environ quatre fois plus vite qu’elle ne dure à l’écoute, si bien que la phrase suivante est prête avant la fin de la précédente. L’utilisateur sent surtout la demi-seconde d’attente sur la première phrase.

```typescript
import { MistralTTS } from '@micdrop/mistral'

const tts = new MistralTTS({
  apiKey: process.env.MISTRAL_API_KEY || '',
  voiceId: 'voice_592', // Marie, voix française
  baseUrl: 'https://api.eu.mistral.ai', // Serveurs européens
})
```

Gradium répond plus vite et propose plus de voix, ce qui compte dans une conversation. Voxtral Speech 3 coûte de 2,8 à 4,5 fois moins cher au caractère et fait un bon fournisseur de secours européen pour Gradium dans le `FallbackTTS`.

## Cas d'usage

### Service public et administration

L'ANSSI et la CNIL poussent les administrations vers des fournisseurs relevant du droit européen. Un assistant vocal ouvert aux citoyens se déploie alors avec des données qui restent en Europe.

### Santé et HDS

Les données de santé exigent un hébergement HDS (Hébergeur de Données de Santé). Gradium en région EU se combine avec un hébergeur certifié sans rompre la chaîne, là où un TTS américain oblige à documenter un transfert hors Union.

### Entreprise et confidentialité

Les conversations internes et les échanges commerciaux touchent au secret des affaires. Les garder chez un fournisseur européen simplifie la cartographie des traitements que réclament les grands comptes.

### Éducation

Un établissement scolaire traite les données d'élèves souvent mineurs, ce qui durcit ses obligations. Un TTS européen épargne au dossier un transfert extra-européen de plus.
