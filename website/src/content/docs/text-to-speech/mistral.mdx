# Voxtral Speech TTS in Node.js

Voxtral Speech 3 reads the answers of your agent in more than 35 languages, with preset voices or a voice cloned from a few seconds of audio. The speech endpoint reads a whole text at once, so `MistralTTS` cuts the answer into sentences and sends the audio of each one as Mistral streams it. A sentence starts playing in about half a second and is generated several times faster than it is spoken, so the next one is ready before the current one ends.

## Installation

```bash
npm install @micdrop/mistral
```

The same package also provides [an agent](../agents/mistral) and [a speech to text](../speech-to-text/mistral). The [providers page](../providers) shows what every provider covers.

## Usage with MicdropServer

```typescript
import { MistralTTS } from '@micdrop/mistral'
import { MicdropServer } from '@micdrop/server'

const tts = new MistralTTS({
  apiKey: process.env.MISTRAL_API_KEY || '',
  model: 'voxtral-mini-tts-3-0', // Default model
  voiceId: 'voice_592', // Marie, French
})

new MicdropServer(socket, {
  tts,
  // ... other options
})
```

## Usage without MicdropServer

```typescript
import { MistralTTS } from '@micdrop/mistral'
import { Readable } from 'stream'

const tts = new MistralTTS({ apiKey: process.env.MISTRAL_API_KEY || '' })

// Audio is raw PCM, 16 bits, mono, at tts.sampleRate
tts.on('Audio', (chunk) => console.log('Audio:', chunk.length, 'bytes'))
tts.on('Failed', (texts) => console.error('Failed:', texts))

tts.speak(Readable.from(['Hello! ', 'What can I do for you?']))
```

## Events

| Event    | Payload    | Description                                                                            |
| -------- | ---------- | -------------------------------------------------------------------------------------- |
| `Audio`  | `Buffer`   | A chunk of audio, PCM 16 bits, mono, at `tts.sampleRate` (24 kHz), ready to be played. |
| `Failed` | `string[]` | Synthesis gave up after an error, with the text that stayed unspoken.                  |

See the [TTS interface](./custom) for the full contract.

## Options

| Option     | Type                      | Default                    | Description                                                         |
| ---------- | ------------------------- | -------------------------- | ------------------------------------------------------------------- |
| `apiKey`   | `string`                  | Required                   | Your Mistral AI API key                                             |
| `model`    | `string`                  | `'voxtral-mini-tts-3-0'`   | Speech model to use                                                 |
| `voiceId`  | `string`                  | `'voice_3150'`             | Preset voice, or the id of a voice saved in your Mistral account    |
| `refAudio` | `string`                  | `undefined`                | A few seconds of speech to clone, base64 encoded, used over voiceId |
| `settings` | `Record<string, unknown>` | `undefined`                | Extra fields of the request body, such as `phoneme_hints`           |
| `baseUrl`  | `string`                  | `'https://api.mistral.ai'` | API address, such as `https://api.eu.mistral.ai` to stay in Europe  |

Voxtral Speech 3 costs $13 per million characters.

## Voices

Each preset voice has a native language and reads the others too. `MistralTTS.listVoices()` returns the full list, the presets and the voices saved in the account:

```typescript
const voices = await MistralTTS.listVoices({
  apiKey: process.env.MISTRAL_API_KEY || '',
})
// [{ id, name, languages, gender, custom }, ...]
```

Pass `language`, such as `fr` or `fr-FR`, to keep the voices that speak it, every locale of the language included. The list is fetched once, then shared by every call of the process for a day. Pass `refresh: true` to fetch it again, after adding a voice to the account.

Mistral also offers voices in Arabic, Catalan, Hindi, Japanese, Korean, Dutch, Polish, Russian, Chinese and more. The Voxtral 2 voices, such as `gb_jane_neutral` or `fr_marie_happy`, still work.

The text can carry emotion and pace tags such as `[emotion=...]`, which Voxtral Speech 3 performs rather than reads out. Ask your agent to write them in its system prompt.
