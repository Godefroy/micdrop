# Voice AI Providers Supported by Micdrop

A Micdrop server hands each part of the call to a provider of your choice, so
you can mix them for cost and quality, run them all locally, or write your own.

- **[Speech to text](../speech-to-text)** transcribes the user.
- **[LLM (Agent)](../agents)** writes the answers.
- **[Text to speech](../text-to-speech)** speaks them.
- **[Realtime](../realtime)** models hear and speak in one connection, in place of the three above.
- **[Classifiers](../classifiers)** turn each turn of the user into typed decisions next to the agent.

Each provider ships as its own npm package. The table shows which part of a

The AI SDK package opens the LLM column to every model the
[Vercel AI SDK](../agents/ai-sdk) supports, Anthropic, Groq or a local Ollama
server included. Any other provider plugs in through a
[custom speech to text](../speech-to-text/custom),
[text to speech](../text-to-speech/custom), [agent](../agents/custom) or
[classifier](../classifiers/custom).

Mistral, Gladia and Gradium cover the three parts of a call with European
companies, as the [sovereign voice AI guide](./sovereign-voice-ai) shows.

## Mixing providers

Each part is a separate option of the server, so every one can come from a
different provider:

```typescript
import { MicdropServer } from '@micdrop/server'
import { MistralAgent } from '@micdrop/mistral'
import { GladiaSTT } from '@micdrop/gladia'
import { CartesiaTTS } from '@micdrop/cartesia'

new MicdropServer(socket, {
  stt: new GladiaSTT({
    apiKey: process.env.GLADIA_API_KEY,
  }),
  agent: new MistralAgent({
    apiKey: process.env.MISTRAL_API_KEY,
    model: 'mistral-medium-latest',
  }),
  tts: new CartesiaTTS({
    apiKey: process.env.CARTESIA_API_KEY,
    voiceId: 'cartesia-voice-id',
  }),
})
```

The speech to text, the agent and the text to speech all have a local
counterpart, so a whole conversation can also run on your machine with the
[local models guide](../local-models).
